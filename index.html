LRAA: Loan Rephasing Assistant

MSc coursework · Python · agentic AI
coursework

A multi-agent assistant that answers customer questions about why a loan's monthly instalment (EMI) changed. It replays a loan's full history to work out what the EMI should be, explains the result in plain language, and hands anything that doesn't add up to a human.

  • Tool-calling agents built with LangChain and Gemini 2.5 Flash, with Pydantic-validated JSON between each stage.
  • Amortisation and EMI maths done with numpy-financial and pandas, so the numbers come from code and not from the model.
  • The intent agent is told never to extract personal data such as names, emails or account numbers.
  • Streamlit front end over sample customer, loan and transaction data.
  • Python
  • LangChain
  • Gemini
  • Pydantic
  • pandas
  • numpy-financial
  • Streamlit
  1. Intent agentclassifies the request and pulls out the loan ID
  2. Loan analysis agentreplays payments, top-ups, part-liquidations and rate changes
  3. Report agentwrites the explanation for the customer
  4. Escalationemails an on-site agent when a discrepancy is found

Malaria detection: CNNs vs ViT vs BLIP-2-style contrastive

MSc dissertation · computer vision
in progress

A comparison of six model types for classifying malaria blood-smear images as parasitised or uninfected, with a focus on whether we can see why a model makes its call.

  • Models: ResNet-18, ResNet-50, ResNet-152 and VGG-19 (ImageNet-pretrained), a ViT-B/16, and a Q-Former trained with an image-text contrastive loss on BLIP-2's frozen ViT-g/14 vision tower.
  • Data handling: patient/slide-aware train, validation and test splits so one patient's images never leak across sets, plus CLAHE contrast enhancement applied identically for every model.
  • Efficiency: the frozen vision tower's output is cached once per image, which makes contrastive training roughly three orders of magnitude cheaper than running it live.
  • Explainability: Grad-CAM for the CNNs and ViT, and Q-Former cross-attention for the contrastive model.
  • Runs on CPU locally and on GPU in Google Colab. Every training script has a smoke-test mode for quick pipeline checks.
